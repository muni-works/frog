Choosing a model

Frog runs on your Mac by default. Every model id says where it runs.

Where models run

local/
This Mac
On Metal. Free and private.
ollama/
Your server
ollama or LM Studio.
cloud/
Frog Cloud
Faster, from your credits.

Add your own

Put models in ~/.config/frog/config.toml. Any OpenAI-compatible server works.

~/.config/frog/config.toml
default_model = "qwen"

[models.qwen]
provider = "ollama"
model = "qwen3-coder:30b"
context_window = 65536       # sent as num_ctx — ollama's default is tiny

[models.lmstudio]
provider = "openai"
base_url = "http://localhost:1234/v1"
model = "qwen/qwen3-coder-30b"

When the cloud is out

When Frog Cloud is out of credits or offline, Frog finishes on your Mac instead. Set FROG_FALLBACK_MODEL to choose which model.
