The web app's first ten minutes

Connect a repo, come back from sign-in already working, and what happens when the credits run out.

1 · Connect a repo

The repo pill opens a picker in the column, not a new page. GitHub access is per repo.

2 · Back from sign-in

You land in the session you started, and the request is already running. No second send.

3 · Out of credits

The web has no local model to fall back to, so Frog finishes the step it's on, saves everything, and offers ways to go on.
