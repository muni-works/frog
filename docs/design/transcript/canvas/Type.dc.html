9. Type and spacing

The app already has a transcript scale and rhythm (the Mac's TurnSpace and Tokens.Size), and the earlier boards drifted from it: they were drawn in the system font at 13. This board sets the new rows inside the real system, in IBM Plex, and proposes three changes to it. Everything here is set in the real faces at the real sizes.

Icons, the live dot and fold chevrons sit in an 18-point box that hangs 26 points into the 32-point gutter. Verbs, thoughts, stats and prose then start on the same line down the page, and the marks read as margin notes.

Change 2: prose stops at 640, boxes still use 720

At 14 points the 720 column runs to about 100 characters a line, past comfortable reading. Paragraphs and lists cap at 640 (about 88). Code, tables, diffs, cards and the composer keep the full 720, so the column's right edge is still drawn by the things that need the room.

Change 3: stats are set in the text face

Time, tokens and speed move from mono to Plex Sans with tabular figures. Digits still don't jiggle, and mono goes back to meaning one thing: this is code, a path or a command.

The rhythm, from loud to quiet

32Between turns. The loudest gap, so a turn reads as one paragraph of work. 20Above the footer: a block plus 4, so the footer belongs to the turn but stands off the last line of prose. 18Between paragraphs of prose. 16Between blocks: prompt to first row, prose to a card or a code box. 12Between prose and a run of lines, either way round. Lines are margin notes: nearer than a paragraph, with air of their own. 24One line: 20 of text in a 24 row, which is also the hover plate's height. Lines in a run touch. 2Between the live row and its stats. They are one unit and move as one.

Small things that add up

−A true minus in "+3 −2", and a real ellipsis where a line is cut. ·The middle dot separates stats, with a normal space each side. Never a pipe or a slash. 0–9Tabular figures wherever numbers tick or stack; proportional in prose. 16The prompt bubble's corner. Its padding is 8 by 14, so one line of prompt is 38 tall and sits on the same 2-point grid as everything else. codeInline code is one size down on a quiet plate and never changes the line's height. 7The hover plate's corner. It bleeds 6 points past the text on both sides, so the words don't move when it appears.
