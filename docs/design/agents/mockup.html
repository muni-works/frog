What each number is

  1. Anchor line at the call. One line in the column where the card was. A Slack-style thread link: name, live step, steps, time. A failure reads in red and links to where it failed. The report still lands in the transcript as text the parent quotes.
  2. Peek. Hover or press space: the last 3 steps, the newest thinking, model and speed. Quick Look, not a sheet. Most checks end here.
  3. Rail spans. One short bar per agent beside its turn (Temporal's timeline), colored by outcome. Chapter dots stay as they are. Hovering a red span names it, and a click goes to its anchor. Memoized like Chapter.cached, so no per-row cost.
  4. Pill. "3 agents · 1 failed" after the live step. Clicking the count lists them in the activity panel, each with Show.
  5. Sidebar. The parent row gets a pie and a count (Things 3). Agents fold under it and unfold only while running or when they need you. A failed agent puts its parent in Needs you. Finished OK: one "› 1 agent done" line.
  6. Thread pane. Opens the agent's real transcript as a tab of the right-hand card (same TranscriptView, so markdown, activity lines and ink match). Opening a failed agent lands on the failing step, expanded (GitHub Actions). Continue as session turns it into a standing child that keeps its log.

Not built in this pass: dragging an agent onto the composer, a graph view of agents, cross-agent messaging UI.
