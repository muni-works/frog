What should we work on?
One chip, not three.Place, branch and worktree were three controls on their own row. They are one chip and one menu now. Switching place changes the model.A cloud repo takes the cloud model you used last; a folder takes that folder's. The status line says so once. What goes away.The Mac's separate Frog Cloud tray and its folder-only chip. The web's "No repo" chip already works this way. Menu rows.28 tall, 7 radius hover plate, a check at the right for the current choice, detail text right-aligned in muted. Filter first.The field at the top takes focus when the menu opens. Arrow keys move, Return picks, Esc closes. After the session starts the place and branch show in the status line with the git state, and only when there is git state to show.
