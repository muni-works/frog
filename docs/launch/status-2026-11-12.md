# Launch status, 2026-11-12

A dated note on where launch stands the day before the Nov 13 launch, from what this repo records:
`git log` (ee125dc6, PR #286), the plan docs, [no-caps-bench.md](../no-caps-bench.md) and
[the Nov 5 status](status-2026-11-05.md). Nothing here was probed live. Where the repo has no
record, it says so.

**Positioning:** "No caps. Your machines. One agent." Frog owns the agent, the engine (tang) and
the hardware path; Frog Cloud is billed by the token when you want more.

## Shipped since Nov 5 (the repo shows it)

92 non-merge commits since Nov 5; PRs #259–#286 merged.

- **Every frog is a node** ([plan](../plans/2026-11-11-every-frog-is-a-node.md),
  [node protocol](../node-protocol.md)):
  - node protocol v2: auth, Ed25519 identity, SPAKE2 pairing on a 6-digit code, `/node` schema 2,
    model identity by weights hash;
  - Mac pairing client and Settings › Lend ("Lend this Mac");
  - `frog.toys/node`, the one-command Linux installer (`site/node.sh`);
  - local node pool with failover mid-stream: a dropped node's partial answer is dropped and the
    turn reruns on the next node with that model (D4);
  - composer chip and device map show where the model runs;
  - models onto paired nodes from the picker, with the fit check (D6; on-disk models only, tang
    has no pull yet);
  - the D7 scheduler replaces the placement stub: earliest estimated finish, KV affinity,
    background calls kept off busy nodes.
- **No caps bench** (#281, #285): `frog-bench swarm`. Qwen3-8B, this Mac (M4 Max) + mew
  (RTX 3090), 6 agents, 15 minutes: 41 / 64 passed vs 21 / 42 on mew alone, 86 → 128 tok/s
  aggregate, no 429s or 5xx. The additivity check fails on both runs: on Qwen3-8B one task got
  slower (edit-json-config 101 → 120 s); on Qwen3-0.6B three of 9 short tasks did. Written up in
  [bench.md §1b](bench.md).
- **One look** ([docs/design/parity/](../design/parity/README.md)): one token source for the
  Mac and web apps; a parity harness renders one fixture session in both, side by side; three
  rounds of parity fixes (rows, ask card, composer, title bar).
- **Session tree replaces background agents** (#282): background Tasks are retired; parallel work
  is a child session the engine owns headless, and `frog --sessions` draws the started-by tree.
  The Mac, iOS and web nest children.
- **`frog login` / `frog logout`** and one local default stated once (first-hour work).
- **Explicit model names** (#280): `cloud/deepseek-v4.1-flash`, `cloud/glm-5.3-flash`,
  `cloud/qwen3-coder-next`. The bull / tree / dart nicknames are gone; old ids still resolve.
- **No silent failures** on the Mac at launch, on app death and in sign-in (#270).
- **Rent vs own** GPU proposal for Frog Cloud base load ([gpu-rent-vs-own.md](../plans/gpu-rent-vs-own.md), #286).
