frog 0.7.0. A first session with no setup, coupon codes, Settings on the web, and a calmer Mac
window, on top of v0.6.4 (Nov 17).

## Install

```sh
curl -fsSL https://frog.toys/install.sh | sh   # CLI, macOS arm64 + Linux x86_64/aarch64
```

The Mac app: [frog.toys/download](https://frog.toys/download). It updates itself (Sparkle).

## Frog Cloud: start without setting anything up

- **Every new account starts with 25¢ of credit,** however it signed up. Connecting GitHub
  brings that to $1, once per GitHub account.
- **A first session needs no repo.** Without GitHub, the web composer starts a scratch
  sandbox and suggests things to build. After the first finished turn, one card offers to
  connect GitHub so Frog can open pull requests on your repos. It shows once. (#423)
- **Coupon codes.** Settings → Billing on the web takes a code and adds its credit. (#414)
- **Signed out, frog.toys is the real app:** the sidebar, a composer that takes your draft
  through sign-in, and a chip for the Mac app. (#410)

## Settings on the web

- **Settings is a mode of the shell,** like Documentation: Appearance, Models, Account and
  Billing in the sidebar, one section in the main column. ⌘, opens it. (#414)

## The Mac window

- **Split panes lose their header pills.** Each pane starts on the line under the title bar;
  the focused pane is the one whose composer is at full strength. (#412)
- **The inspector's tabs sit in the title row,** and its header lines up with the top of
  the window. (#412)
- **Quieter column edges, and a sidebar you can drag.** The lines beside the sidebar and the
  inspector use a softer colour on the Mac and the web, the composer's resting border
  matches, and the left sidebar resizes like the right one. (#407, #409, #412)
- **The Preview tab is one browser bar over a page** on both apps. This fixes the broken
  toolbar on the web in 0.6.4. (#416)

## Local models

- **A short list per machine.** Each machine offers the best coding model that fits it and
  at most two smaller ones, with the rest behind More models. What is already on the machine
  always shows. (#413)
- **Rows explain themselves:** what the model is for, its size against the machine's memory,
  and where it downloads from. Buttons say what they do ("Get · 18 GB", Load, Stop). (#413)
- **Loading ends.** A model row no longer spins forever when the machine itself is stuck.
  (#413)
- **Apple Intelligence answers.** Picking it said "Loading apple into memory" and then
  nothing. It now says what it is doing, and no longer waits five minutes when its port is
  taken. (#415)

## Sessions

- **A quiet or dead child becomes a question.** When a subagent or a child session stalls
  or dies, the parent asks what to do instead of waiting in silence. (#411)
- **A one-line answer keeps the transcript following** to the end on the Mac. (#408)
