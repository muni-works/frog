frog 0.3.0. Everything since v0.2.0 (Nov 12): 82 commits.

## Install

```sh
curl -fsSL https://frog.toys/install.sh | sh   # CLI, macOS arm64 + Linux x86_64/aarch64
```

The Mac app: [frog.toys/download](https://frog.toys/download). It updates itself (Sparkle).

Tarballs are checksummed (`SHA256SUMS`) and minisign-signed (`*.minisig`); install.sh checks both.

## The one that matters: turns no longer hang

A model call had a connect timeout and nothing else. Once the socket was up, a dead
downstream or a stream that stalled mid-flight hung the turn indefinitely — the twenty-five
minute stall that started this whole line of work. A model request is now bounded
(ten minutes by default, `request_timeout_secs` per profile), the provider's own `retry-after`
is honoured instead of our fixed 1/2/4 s backoff, and a session reports what it's waiting on
rather than looking merely busy. (#305)

## Questions you can answer properly

- **Ask me to pick several.** `multi` has been in the Ask schema since it was written and was
  never used, because the tool's description never mentioned it — so every card was
  single-pick. The description says when it applies, and the person answering now decides the
  arity rather than inheriting the model's guess: pick one, pick several, or type your own,
  then confirm. (#312)
- **A question is the tree's, not one session's.** A question is now recorded in a ledger
  beside the session log, so a manager and its worker can't ask you the same thing twice, and
  "never answered" stays distinguishable from "answered" across restarts. (#304, engine half)

## Auto mode stops interrupting you

In auto mode a flagged call is now denied with a reason and the model moves on, instead of
raising a card. The chief still gets its chance to decide first — a grant is a decision, not a
prompt. (#303)

## Knowing what's running

- **`Models`** answers "what can I actually run right now?" — every resolvable model with its
  provider, context window, cost, and whether its credential is live. (#307)
- **The composer queues into the running turn.** A follow-up you send while a turn is going is
  ingested at the next tool-call boundary, in order, so the model reads it as part of the work
  instead of after it. (#306)
- **The sidebar's PRs match the composer's.** A thread's PRs are read from the bound list
  rather than guessed from git ancestry, so "3 PRs, all merged" says the same thing in both
  places — including for a thread with no conversation open. (#317)
- **One accordion level.** Expanding a session shows its children directly; the extra
  done/failed fold is gone. A finished child's check ends once you've looked at it. (#317)
- **Archiving what you're reading clears the view.** (#316)

## Frog Cloud

- **The upstream is opaque.** A Frog Cloud turn reads as "Frog Cloud" whoever actually
  proxied it. `served_by` and `x-frog-upstream` stay truthful in the ledger and session log,
  and cost stays the real number — a cache miss is still debugged from the data, just not
  labelled in the UI. Bring-your-own providers are hidden, not removed. (#310)
- **No cloud-to-local fallback.** A cloud error pauses the turn and says why, instead of
  silently continuing on a different model than the one you chose. (#302)

## Look and feel

- Solid text colours on the Mac, matching the web's `fg`/`muted`/`faint`, plus a readability
  pass — one token source, one transcript style, a parity harness that holds them together.
  (#309)

## Fixes

- The `macos-app` CI job had been failing on every PR since the Watch app was cut: the targets
  were deleted from `project.yml` and the build step stayed behind. Removed. (#313)
- Two test suites were failing on unchanged code — fixed sleeps that lost the race on a loaded
  runner are now bounded condition-waits (#311), and a socket test no longer runs on a frozen
  clock, where tokio's auto-advancing time expired its connect timeout before the accept task
  got a turn (#318). Main is green again.
- A test asserting a "This Mac" label the composer never draws now asserts the model that
  decides the chip exists. (#315)
- The empty Changes card fills the inspector height. (#301)

## Engine

- `frog-engine` protocol: `waiting` on `Status` (a call in flight, with elapsed time, attempt
  and `retry_after`), `prs` on the session header, the composer's `FollowUpsIngested`.
- Every test that was written to catch a bug is shown to fail with the fix reverted
  (`CONTRIBUTING.md`).
