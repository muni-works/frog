frog 0.6.0. Everything since v0.5.0 (Nov 15).

## Install

```sh
curl -fsSL https://frog.toys/install.sh | sh   # CLI, macOS arm64 + Linux x86_64/aarch64
```

The Mac app: [frog.toys/download](https://frog.toys/download). It updates itself (Sparkle).

## One right sidebar, on the Mac and on the web

- **The same panel in both apps.** Changes, Terminal and Preview are always there as icon
  tabs. The panel is a rounded card you can drag wider or narrower (360 to 560). File rows
  are one line: name, folder, lines added and removed. Commit and Open PR sit at the bottom,
  and one empty state says "No changes yet". The Mac no longer borrows system styling for
  it. (#379, #380)
- **Preview on the web.** A Frog Cloud session's dev server shows in the Preview tab, with
  screenshots and click-to-mention, as on the Mac. It needs the matching Frog Cloud sandbox,
  which rolls out separately; until then the tab says it isn't there yet. (#372)
- **Then and now on the Mac.** The preview's before-and-after view opens from the toolbar
  and from the timeline. (#373)
- **A failed command in your terminal reaches frog.** When a command you ran in the
  Terminal tab fails, the model hears about it without being asked. (#371)

## The web, handled more gracefully

- **A link you gave frog is a read.** A URL you wrote, or one an earlier search or fetch
  returned, is fetched without a card whatever it looks like. Only URLs the agent composes
  go through the stricter check. (#378)
- **A refused site stays refused.** When a fetch is denied, the model is told it is about
  the site, not the tool, so it doesn't reach for `curl` instead. (#378)
- **Search works when your own search doesn't.** A SearXNG that can't be reached (another
  network, a server that is down) falls back to Frog Cloud search when Frog Cloud is
  connected, and the result says so. A dead backend fails in 4 seconds, not 20. (#375)
- **A hermetic run never takes a search key from the machine.** (#369)

## Turns that just stopped

- **An empty reply is asked again.** A model that returns nothing at all (no text, no tool
  call) used to end the turn in silence. frog asks once more; a second empty reply ends the
  turn with a line saying so. (#377)
- **Stop clears what a parent had queued.** A stop with `clear_queue` voids a parent's
  parked message. (#362)
- **A resumed session serves only from its own folder.** (#365)

## Frog Cloud pricing

- **Cost plus 10%.** Models served through OpenRouter are billed at what each request cost
  there plus 10%. The pricing page shows where each model's price starts today; a request
  costs more when OpenRouter routes it to a dearer provider. (#374)
- **Plans are Pro, Max and Ultra,** shown as dollars of usage a week: $5, $25 and $50. (#374)
- **Sign-up credit is $1.** Adding credit by card adds the card fee as its own line. (#374)

## Smaller things

- **Typing goes to the composer.** After clicking a message in the transcript, typing lands
  in the composer on the Mac. (#376)
- **`open_pr_when_done = "auto"`** opens a draft PR when the work is done. (#370)
- **Zero-prefill turns:** the design, warm-up tests, mid-turn drafts, and node and
  background warm-ups. Not measured yet. (#367)

## Tests and CI

- A hung test ends the run and is named. (#368)
- The prompt budget test measures the same prompt on every machine. (#361)
- Sandboxed-shell tests skip when the run is already sandboxed. (#363)
- Pane shells wait for their prompt; Mac tests restore the transcript flag. (#364)
- CI is ready for a merge queue. (#366)
