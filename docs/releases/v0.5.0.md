frog 0.5.0. Everything since v0.4.0 (Nov 14).

## Install

```sh
curl -fsSL https://frog.toys/install.sh | sh   # CLI, macOS arm64 + Linux x86_64/aarch64
```

The Mac app: [frog.toys/download](https://frog.toys/download). It updates itself (Sparkle).

## The one that matters: agents carry less and waste less

- **The fixed prompt is about half the size.** Seventeen rarely used tools load on demand
  through `ToolSearch` instead of riding along on every call: 33.9k → under 20.1k
  characters headless, with a test that fails if it grows back. Your own `FROG.md` and skill catalog
  still load on top of that. (#354)
- **Delegation pays for itself.** Guidance on when splitting is worth it, briefs that give a
  child a head start, children that can ask their parent, and DeepSeek V4.1 Flash as the
  model a new session starts on while Frog Cloud lists it. (#353)
- **Fewer calls per task.** `Grep` returns context, `Read` takes several files, Bash steers
  plain reads to the file tools, a habitual `unsandboxed` is downgraded, and a turn that has
  gone many calls without progress is nudged. (#355)
- **The common wasted calls succeed.** Tool inputs that used to fail on a technicality now
  do what was meant. (#345)

## One question, asked once

- **A session tree never asks you the same thing twice.** Each session keeps a ledger of
  what it asked and how each question stands, and `Ask` checks the whole tree's ledger
  before it opens a card. (#304)
- **Auto mode doesn't stop to ask.** A call that would need your approval is denied with a
  note and the turn moves on, instead of a card nobody is there to answer. The sandbox also
  allows ptys, so `xcodebuild test` runs inside it. (#303)
- **Opening a PR is offered, not silent.** `[git] open_pr_when_done = "off" | "ask"`, default
  `ask`: when the work is done, the git line's Open PR action is its one emphatic chip.
  `auto` parses but reads as `ask` for now. (#329)

## Threads that looked stuck

- **A finished thread stops spinning.** When several sessions changed within one listing
  window, the sidebar re-read only the last, and a thread whose turn had just ended kept its
  spinner for hours. Every changed session is re-listed now. (#356)
- **A wait on a finished job is refused.** A long `sleep`-then-check that names only jobs
  that have already exited fails with a pointer to `JobOutput`, and a job that printed
  nothing says so in its `job-done` message. (#356)
- **A log from a newer frog opens.** An event an older build can't name is skipped instead
  of the whole session being called corrupt. (#356)
- **A busy Frog Cloud doesn't end the turn.** (#347)
- **Long histories still compact.** When the history can't fit the model's window, it is
  summarized in parts. (#346)

## Transcript

- `cd … &&` rows lead with the command, a worktree that removed itself is quiet, and wake
  wording is plainer. (#352)
- Approval copy is true in Frog Cloud, and a denied command is followed by a sentence
  saying what happened. (#349)
- Frog knows it's Frog and how it takes MCP servers; archiving twice is a no-op. (#344)
- **Mac prices are right.** Output prices were scaled to per-million twice
  (`$1440000.00/M` for a $1.44 model), and picking a cloud model no longer asks. (#322)

## Hardening

- **Tool sandbox:** Linux egress, environment scrubbing, credential files off limits to
  `Read`, `WebFetch` exfiltration, capability drops. (#334)
- **`--serve-ws`, `--listen` and the git credential helper:** a gateway now has to send
  `FROG_SERVE_WS_TOKEN` (or set `FROG_SERVE_WS_INSECURE=1`). (#335)
- **Sidecars:** a password-field guard, `frog-apple` auth and parsing, `frog-chromium`
  removed. (#336)
- **Apps:** node id validation, the bridge token in the keychain, a cloud-only web app, one
  dollar formatter. (#337)
