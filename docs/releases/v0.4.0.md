frog 0.4.0. Everything since v0.3.0 (Nov 13).

## Install

```sh
curl -fsSL https://frog.toys/install.sh | sh   # CLI, macOS arm64 + Linux x86_64/aarch64
```

The Mac app: [frog.toys/download](https://frog.toys/download). It updates itself (Sparkle).

## The one that matters: opening a conversation no longer opens a browser

Every session open used to spawn MCP connects, and any server answering 401 launched the
system browser — unasked, per conversation, with a 15-minute listener left behind. A 401 on
connect now marks the server **needs auth** and stops: the settings panel and a transcript
card offer "Sign in", and that is the only thing that opens a browser. A decline is
remembered. (#330)

## Tool rows read as what they did

- **A short result is on its own line.** `SendMessage`, `ArchiveSession`, `MoveSession`,
  `RenameSession` and friends no longer take two clicks to reach a one-sentence answer — the
  sentence is the row, with nothing to click and no repeated label. (#331)
- **Typography at the web's rhythm.** 12.5 pt at 1.6 line height (≈20 pt rows), gist text at
  `#a3a3a3` (8.3:1 contrast, where the old tertiary was 2.6:1), the raw argument as an
  uncapitalised mono command until a gist lands, failures keeping their verb in `warn`.
  Row height no longer jumps when gists arrive. (#339)
- **Yolo is one row.** A `Bash` call that leaves the sandbox tags its own row instead of
  adding a second notice saying the same thing; the hosts grant keeps its row, since naming
  the hosts is information the row can't carry. (#343)

## The sidebar settles down

- **The git badge survives hover.** It used to pop out of the layout after 450 ms under the
  pointer; it now stays as long as you're on the row, and the row's age text is gone
  (`14m`/`1h` competed with the badge for the same slot). (#340)
- **The tree has rails.** The org tree drew no guide at all — children relied on indent
  alone. Rails now run both list modes at one indent, depth is uncapped (narrowing past
  four levels), and a selected nested row no longer swallows its own guide. (#327)
- **Sessions file under a live parent.** Archiving a manager used to orphan every session
  it started — they fell to the tree root pointing at a ghost. Children now resolve to the
  nearest live ancestor, or stand at the root honestly. (#326)

## Engine

- **Background results reach the running turn.** A `run_in_background` job that finished
  mid-turn used to stay invisible until the turn ended; its notice now lands at the same
  tool boundary as session messages, so the model isn't reasoning about a stale world.
  (#328)
- A listing without `prs` decodes again — the field's default didn't cover Swift's
  synthesized `init(from:)`, and older logs and fixtures threw `keyNotFound`. (#325)

## The web app

- **Mac-only dead ends became download chips.** Six places said "From the Mac app" and could
  do nothing; each is now a quiet chip at `/download`, hidden on phones and when a paired
  machine already exists. (#324)
- Web rows match the Mac's: the verb drops on a finished row, the label is never said
  twice, and honest before/after snapshots for the tree exist in `docs/design/tree-rails/`.
  (#332, #342)

## Housekeeping

- v0.2.1 (broken, CLI tarballs missing) is now marked pre-release so `latest` stays honest.
- `IdleCPUTests` skips with a reason when the runner never goes quiet, instead of reporting
  a busy machine as the view failing to idle. (#323)
- The scanner-timing test survives a busy CI runner. (#341)
