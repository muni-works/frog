# Frog 0.2.1

- **One model picker.** Models and where they run in one menu: your machines in blue, Frog Cloud in green. Picking a model on a machine that holds another swaps it.
- **Settings › Models.** Every machine, This Mac included, gets its own page: what it's running, its models on disk, Share, Rename and Unpair. Pairing moved here.
- **The composer tray.** One rounded surface: the git line on top (branch, diff, PR state, one action), and +, mode, model and a single mic/send/stop button below. New sessions default to Auto.
- **Interactive visuals.** Ask Frog to explain something visually and it draws an interactive widget in the transcript.
- **Tool-call summaries.** Shell, web and MCP calls get a one-line summary of what they did. Local sessions never send tool output to Frog Cloud for this.
- **Transcript polish.** The stray green bar on web replies is gone; long code, wide tables, RTL text and huge diffs render cleanly on Mac and web.
- **Model colours.** Cloud is green and local is blue, everywhere.
