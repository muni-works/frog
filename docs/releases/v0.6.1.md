frog 0.6.1. Two fixes on top of v0.6.0 (Nov 16).

## Install

```sh
curl -fsSL https://frog.toys/install.sh | sh   # CLI, macOS arm64 + Linux x86_64/aarch64
```

The Mac app: [frog.toys/download](https://frog.toys/download). It updates itself (Sparkle).

## The Mac app could freeze while resizing

- **The freeze.** On macOS 27 the app could hang for good during a resize, at full CPU,
  needing a force-quit. The right sidebar's card was drawn as glass inside another glass
  container while holding things that take the keyboard (the terminal, the preview, the
  tabs), and the system's search for the next keyboard focus never finished. The card now
  draws the same opaque panel as the thread list. 0.5.0 and 0.6.0 were both exposed. (#388)
- **The resize grip is easier to hit.** The sidebar's grip was an invisible 8 point strip;
  a press just off it dragged the whole window. It now reaches past the card's edge, shows
  a bar on hover, and the resize cursor appears only over the grip. (#388)

## The sandbox no longer waves through what it can't contain

- **A sandboxed command still runs without asking, with six exceptions.** A push, a
  publish, discarded changes (`reset --hard`, `clean -f`, `checkout -- .`, `restore`),
  rewritten history (`rebase`, `commit --amend`), killing a process and changing a system
  setting used to run sandboxed with no check in any mode. They are now checked sandboxed
  or not: in Auto the small model lets it run when your request covers it and denies it
  with a note otherwise; Ask and Accept edits show a card; `-p` in those modes refuses it.
  Yolo is unchanged. (#387)
- **Why those six.** The sandbox is a write fence around the project. It does stop `sudo`
  and deleting or changing files outside the project. It doesn't stop a push landing on a
  remote, your own work being thrown away, or a `kill` or `defaults write` reaching outside
  it. (#387)
- **Expect a few more checks.** The match is on the command's text, so a harmless
  `git restore --staged` or `git rebase --abort` is checked too, and an agent stopping its
  own dev server costs one more check. (#387)

## Tests

- The Mac test suite no longer hangs on macOS 27, and a hung test fails by name. (#384)
