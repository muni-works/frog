frog's first stable release. Everything since v0.1.1-rc6 (Oct 31): 52 pull requests.

## Install

```sh
curl -fsSL https://frog.toys/install.sh | sh   # CLI, macOS arm64 + Linux x86_64/aarch64
```

The Mac app: [frog.toys/download](https://frog.toys/download). It updates itself (Sparkle).

Tarballs are checksummed (`SHA256SUMS`) and minisign-signed (`*.minisig`); install.sh checks both.

## Highlights

- **Every frog is a node.** Pair your machines with a code (SPAKE2), lend a Mac from Settings › Lend, and put models on paired nodes from the picker. The node scheduler places work across the pool, shows where each model runs, and fails over mid-stream when a node goes away. (#264, #265, #268)
- **No caps.** Parallel agents spread across the node pool, with a swarm bench to measure it. (#281, #285)
- **The session tree.** Parallel work is child sessions in the tree; background agents are retired. A child's pending approval reaches its parent as status, and modes are inherited. (#282, #257)
- **One look on Mac and web.** One token source, one transcript style, one ask card, a parity harness that keeps them together. (#273, #275–#279, #283)
- **First hour.** One local default model, `frog login` / `frog logout`, a shorter README. The Mac app no longer fails silently at launch, on engine death, or in sign-in. (#269, #270)
- **Explicit model names.** Frog Cloud models are named for what they are; `bull`, `tree` and `dart` are gone. (#280)
- **Two-tier model policy.** Frog Cloud for the platform's own calls, your key (BYOK) for your sessions, no cross-provider fallback. One retry policy: 429/5xx back off three times with one notice; 401/402/404 fail at once with the fix. A session only starts on a model its gateway lists. Resume keeps the session's model. (#235, #231)
- **Billing you can read.** Typed events for 402 refusals, the out-of-credit end shown in the CLI and app, pricing in dollars per token. (#241, #259, #236)

## Engine

- Auto-continue a reply cut off at the output limit; the Frog Cloud output cap is 32k tokens. (#237)
- Retry a connection reset mid-stream, inside the retry budget. (#240)
- The model is told when messages are waiting for it. (#256)
- Notifications are the model's call via a Notify tool, not every turn. (#252)
- yolo mode never shows egress cards; one quiet row instead. (#243)
- cwd-gone reaches the model; child-cancel and deliver-boundary fixes. (#239)

## Security

- Sandbox escapes closed: git config/hooks and toolchain binaries in writable caches stay read-only; sandboxed commands don't inherit `*_API_KEY`. (#247)
- Data-carrying web reads (long queries, path segments, search terms) go to the classifier; secret-returning MCP reads ask. Links from MCP servers, the sandbox and the edge open only as http(s) on web. (#247)

## Mac app

- One Frog per machine (flock); a second copy hands over to the running one. (#251)
- Worktrees live in the composer; the app names a worktree's owner instead of spawning into it. (#234, #242)
- Panes: maximize, a visible divider, a preview that pops out. (#255)
- Perf: the sessions watcher costs 0.16% of a core instead of 9%; a streamed row costs 2 turn bodies, not 254; composer typing is O(edit). (#254, #258, #260, #267)
- Transcript type ramp and spacing, diagrams that fit inline at 720pt, an outcome card for a worker's claims. (#253, #250, #249)
- Fixed the launch beachball from the checkout() walk. (#244)

## Web

- Audit and fuzz fixes: connection state, IME, a11y, error copy; billing portal errors explained. (#260, #266, #274, #236)
