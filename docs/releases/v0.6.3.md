frog 0.6.3. One composer for the Mac and the web, on top of v0.6.2 (Nov 16).

## Install

```sh
curl -fsSL https://frog.toys/install.sh | sh   # CLI, macOS arm64 + Linux x86_64/aarch64
```

The Mac app: [frog.toys/download](https://frog.toys/download). It updates itself (Sparkle).

## The composer

The box you type in is now the same design in both apps, built from one spec
(`docs/design/composer/spec.md`) and one set of shared test cases. (#395, #396, #397)

- **Two rows at rest.** The field, then the controls: attach, where it runs, the mode, the
  model, and one round action button. The card has a plain 1px border and no shadow or glass,
  like the rest of the window.
- **Pick where it runs in one place.** Before the first message, one chip names the place
  and its branch, and one menu chooses it. On the Mac that menu lists folders on this Mac,
  your Frog Cloud repos and Just chat, with Branch and New worktree below; the separate
  branch and worktree chips and the Frog Cloud repo picker are gone. On the web it lists
  your repos and Branch. Both menus have a filter and take a pasted GitHub URL.
- **Choosing a branch on the Mac now does something.** The branch menu was never given any
  branches. A branch picked before the first message is the new worktree's base, or the
  checkout switches to it when New worktree is off. On the web, the branch is the base of
  the new cloud session.
- **A status line, only when there's something to say.** One optional row at the top of the
  card shows the first of: an error, a question (Yolo, Merge, Archive), a notice, or the
  session's git state with its one next action. Errors keep your draft and say what to do
  in a button. On the Mac, the Yolo, Merge and Archive confirmations moved here from a
  dialog.
- **Queued follow-ups are chips.** Messages sent while Frog is working show above the field
  and each can be removed, in place of a bare count.
- **The action button shows what it will do:** dictate, listening, send, sending, stop or
  queue. Only Send is green.
- **Models show where they run** with a cloud, laptop or server icon in place of a dot.
- **Menus open above the card** and never cover what you're typing.

## Fixes

- **⌘. on the web does one thing.** With a permission card on screen it used to both deny
  the step and change the mode. It now answers the card, and changes the mode only when no
  card is up. (#396)
- **A refused microphone ends dictation** and the message reads "Needs mic access to take
  dictation". (#396, #397)

The engine and the CLI are unchanged from 0.6.1.
