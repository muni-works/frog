# Install

Frog runs in three places. Pick the one you want.

<!-- only: mac -->
You're in the Mac app already. It updates itself.
<!-- end -->

<!-- only: web -->
You're on the web already. Nothing to install: sessions run in Frog Cloud.
<!-- end -->

## The Mac app

Download it from [frog.toys/download](https://frog.toys/download).

## The terminal

```sh
curl -fsSL https://frog.toys/install.sh | sh
```

macOS on Apple silicon, and Linux on x86_64 or aarch64.
