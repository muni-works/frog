# Automations

An automation will be a task Frog repeats without you, at a set time or when something happens, such as CI failing.

## Today

Automations don't run yet. Frog has no scheduler, so nothing repeats on its own, and Settings › Automations stays empty.

## How they'll work

You'll make one by doing the task once in a conversation and saying "keep doing this". Settings › Automations will show each one's week: every run, what it cost in dollars, and any run that waits on you.

## Until then

- Start the task yourself in a new session when you need it.
- A [skill](https://frog.toys/docs/skills) can hold the steps, so starting it is one message, such as `/weekly-report`.

## Automations, skills and rules

- An **automation** decides when a task runs.
- A **skill** holds how to do the task. See [Skills](https://frog.toys/docs/skills).
- A **rule** applies to every turn, whatever the task. See [Rules](https://frog.toys/docs/rules).
