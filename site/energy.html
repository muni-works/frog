Wh per task is every run's energy, failed attempts included, divided by the tasks passed. A model that needs three tries pays for all three.

How it's measured

The Mac's System Management Controller reports how much power the whole machine draws from its supply (PSTR, in watts). Frog reads it ten times a second, without root, and adds it up over each task.

  • Idle comes off first. Right before each run, with the model loaded, frog waits two seconds for the Mac to settle and measures its power for five seconds doing nothing. That baseline times the run's duration is subtracted, so what's left is the extra energy the task caused. Measuring before every run, not once per suite, keeps up with the Mac's own drift.
  • Only the turn counts. Measurement runs from the prompt to the answer: the model thinking, frog's tools, the commands it runs (tests included). The bench's own pass/fail check afterwards is left out.
  • Runs are hermetic. Each task starts from a clean copy of its repository, and frog sees only that repository: none of the machine owner's instructions, skills, MCP servers or search.
  • The chip's counters are kept as a breakdown. Apple silicon also counts GPU and Neural Engine energy per component, and the raw runs below include those. They aren't the headline: on macOS 27 the CPU and memory counters stopped advancing on every Apple silicon chip (macmon#76), and they never saw the rest of the machine anyway.

What's left out

  • Manufacturing. Making the Mac, the servers and the network costs energy too. None of it is here.
  • The network, between the Mac and a hosted model.
  • Power supply losses upstream of the sensor, which are small on a laptop and larger on a desktop's supply.
  • Downloading the model, a one-time cost that's large for local models.

And some noise stays in: anything else the Mac does during a run lands in the measurement, and the idle baseline moves with it. On the same Mac, idle measured between 12 and 19 W across sessions. Runs are repeated, and the raw numbers are all below, so you can see the spread.

Run it yourself

The suite and the bench are in the repository. On an Apple silicon Mac:

cargo run --release -p frog-bench -- run -m apple/on-device -r 3
cargo run --release -p frog-bench -- export ~/.local/share/frog/bench/<run>/results.jsonl

Close what you can first; the idle baseline is only as quiet as the Mac.
