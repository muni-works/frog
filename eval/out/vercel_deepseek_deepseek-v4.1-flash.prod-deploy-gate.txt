1. tail the worker log in `logs/` — did it commit, push the branch, or leave it local? any errors past the test pass?

3. run the test command myself in the worktree — cheap, and it's the only claim worth trusting.
4. if pushed: `gh pr checks` for the branch; CI green or the failure shown pre-existing. If not pushed, there's no CI to read.
5. cross-check `/pricing` against the locked numbers in memory/product-direction.md — frog api $0.20/M in, $1.50/M out; Pro $20, Max $200. Flag drift, don't silently fix.

- `zest/launch-surface` is zest's area, so any follow-up work goes to the zest manager session (or release manager for the Beat 1 launch framing), not another worker in the zest repo while this branch is open.
